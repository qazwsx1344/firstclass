# Lensme Website Renewal — Design System

> 이 문서는 `Lensme/` 프로젝트의 메인 페이지(`index.html`)와 실제 연결된 스타일시트(`css/main.css`, 상위 폴더의 `../css/default.css`)를 기준으로 정리한 서브페이지 제작용 디자인 가이드입니다.
>
> **기준 파일:** `Lensme/index.html`, `Lensme/css/main.css`, `css/default.css`  
> **주의:** 이 문서는 현재 구현된 디자인을 기록합니다. 메인 페이지의 디자인을 변경하거나, 코드에 없는 디자인 토큰을 새로 정의하기 위한 문서가 아닙니다.

---

## 1. Project Overview

### 사이트 목적

렌즈미의 렌즈 상품과 브랜드 콘텐츠를 소개하고, 사용자가 제품 및 혜택을 탐색한 뒤 매장 예약·방문 등 다음 행동으로 이어지도록 돕는 웹사이트입니다.

메인 페이지에서 확인되는 주요 콘텐츠는 다음과 같습니다.

- 메인 비주얼 및 예약 CTA
- 진행 중인 혜택
- 나만의 렌즈 찾기
- BEST/NEW 상품
- 사용자 리뷰
- 브랜드 및 제품 관련 콘텐츠
- 매장 예약·픽업 안내
- 회사 정보와 SNS, 정책 링크가 포함된 Footer
- 가상피팅, 안경쇼핑, 가맹안내, 카카오 상담으로 구성된 플로팅 메뉴

### 디자인 방향

- **브랜드 인상:** 라벤더 계열을 중심으로 부드럽고 감성적인 인상을 전달합니다.
- **정보 전달:** 상품 이미지와 프로모션 배너를 크게 보여주고, 제목·설명·CTA를 붙여 콘텐츠 목적을 빠르게 이해하도록 합니다.
- **탐색 중심:** 상품 카드, 리뷰 슬라이더, 혜택 카드 등 이미지 중심의 콘텐츠로 여러 상품과 정보를 둘러보게 합니다.
- **행동 유도:** 예약하기, 더 찾아보기, 전체보기, 매장찾기 등 짧고 명확한 CTA를 사용합니다.

위 내용은 코드와 화면 구성에서 확인되는 디자인 특성에 대한 해석이며, 실제 이용자 조사 결과를 의미하지는 않습니다.

## 2. Brand Identity

### 핵심 시각 요소

| 요소 | 현재 구현에서 확인되는 특징 | 서브페이지 적용 기준 |
|---|---|---|
| 대표 컬러 | 라벤더 `#AC97DC` | 주요 강조 영역, 브랜드 배경, 선택된 메뉴 등에 사용 |
| 보조 컬러 | 퍼플 `#7863A8`, 연한 라벤더 `#f5f1fa` | CTA, 강조 텍스트, 부드러운 배경 등에 사용 |
| 기본 텍스트 | 딥 퍼플 그레이 `#292536` | 제목과 본문 등 기본 텍스트에 사용 |
| 기본 배경 | 오프화이트 `#FEFEFC` | 페이지와 콘텐츠 기본 배경 |
| 이미지 표현 | 제품·프로모션·리뷰 이미지를 크게 노출 | 이미지 비율과 모서리 곡률을 일관되게 유지 |
| 형태 | 둥근 모서리와 pill 형태 CTA | 카드, 이미지, 버튼에 적용하되 컴포넌트별 기존 수치 준수 |

### 브랜드 표현 원칙

1. 라벤더 컬러를 핵심 브랜드 단서로 유지합니다.
2. 넓은 이미지와 충분한 여백을 활용해 콘텐츠를 구분합니다.
3. 제목은 딥 퍼플 그레이로 읽기 쉽게 표현하고, 필요한 단어만 퍼플로 강조합니다.
4. 둥근 모서리와 pill 형태를 반복해 부드러운 인상을 유지합니다.
5. 서브페이지에서도 메인 페이지와 동일한 Pretendard 계열 글꼴과 컨테이너 규칙을 우선 적용합니다.

## 3. Design Principles

### 3.1 콘텐츠 우선순위가 분명해야 합니다

페이지 상단에는 페이지 제목과 핵심 설명을 배치하고, 그 아래에 사용자가 이해하거나 선택하는 데 필요한 콘텐츠를 순서대로 제공합니다. 메인 페이지처럼 이미지가 중요한 콘텐츠는 이미지가 먼저 인식되도록 구성합니다.

### 3.2 공통 UI는 재사용합니다

Header, GNB, Footer, CTA 버튼, 카드, 콘텐츠 이너의 규칙을 페이지마다 새로 만들지 않습니다. 기존 클래스와 스타일을 먼저 확인하고 공통 컴포넌트로 재사용합니다.

### 3.3 장식보다 정보 가독성을 우선합니다

강조 컬러는 모든 텍스트에 적용하지 않고, 제목의 일부·CTA·선택 상태 등 필요한 곳에 제한적으로 사용합니다.

### 3.4 PC와 모바일의 정보 흐름을 유지합니다

화면이 좁아지면 열 수와 정렬을 조정하되, 제목 → 설명 → 콘텐츠 → CTA의 의미와 순서는 가능한 한 유지합니다.

### 3.5 기존 메인 페이지를 기준으로 확장합니다

서브페이지 제작 과정에서 메인 페이지의 컬러, Header, Footer, 컨테이너, 공통 버튼을 임의로 변경하지 않습니다. 공통 규칙 변경이 필요하다면 먼저 영향 범위를 확인합니다.

## 4. Color System

### CSS 변수

아래 변수는 `:root`에 실제 정의된 값입니다. 서브페이지에서는 동일한 변수명을 우선 사용합니다.

| 변수명 | 실제 값 | 확인되는 역할 |
|---|---|---|
| `--color-background-brand` | `#AC97DC` | 브랜드 배경 및 강조 컬러 |
| `--color-text-primary` | `#292536` | 기본 텍스트 |
| `--color-background-default` | `#FEFEFC` | 기본 페이지 배경 |
| `--color-lavender-mist` | `#f5f1fa` | 연한 라벤더 및 비주얼 페이지네이션 활성 상태 |
| `--color-text-on-brand` | `#FEFEFC` | 브랜드 배경 위 텍스트 |
| `--color-action-primary` | `#7863a8` | 주요 액션 컬러 |
| `--color-action-secondary-hover` | `#7863a8` | 보조 액션의 Hover 컬러 |
| `--color-action-secondary` | `#ac97dc` | 보조 액션 컬러 |
| `--color-soft-white` | `#fefefc` | 부드러운 흰색 |

### CSS에서 직접 사용되는 추가 색상

다음 색상은 변수로 선언되지 않고 선택자에 직접 작성되어 있습니다. 기존 화면과 같은 표현이 필요한 경우 해당 컴포넌트의 기존 값을 따릅니다.

| 값 | 사용 위치 및 목적 |
|---|---|
| `#fff` | 흰색 텍스트 및 아이콘 표현 |
| `#f5f3f5` | 상품 이미지 영역의 배경 |
| `#625e6a` | 상품의 보조 정보 텍스트 |
| `#8b849b` | CSS 내 보조 텍스트 계열 선언 |
| `#f5f5f5` | 일부 콘텐츠 배경 |
| `#625087` | 매장 픽업 버튼 Hover |
| `#A78FD2` | GNB 서브메뉴 배경 |
| `#B494E5` | 플로팅 메뉴 원형 배경 |

### 사용 규칙

- 기본 본문과 제목은 `--color-text-primary`를 우선 사용합니다.
- 기본 페이지 배경은 `--color-background-default`를 사용합니다.
- 브랜드를 강조하는 배경은 `--color-background-brand`를 사용합니다.
- 브랜드 배경 위 텍스트는 `--color-text-on-brand`를 사용합니다.
- CTA는 기존 컴포넌트에서 사용한 `--color-action-primary` 또는 해당 버튼의 실제 CSS 값을 확인한 뒤 적용합니다.
- 비슷해 보인다는 이유로 새로운 보라색이나 흰색 코드를 추가하지 않습니다.
- 변수에 정의되어 있다는 이유만으로 모든 변수를 모든 컴포넌트에 적용하지 않습니다. 실제 사용 위치와 역할을 확인합니다.

## 5. Typography

### 글꼴

- 기본 글꼴: `"Pretendard Variable", Pretendard, sans-serif`
- HTML에서 `../font/css/pretendardvariable.css`를 불러옵니다.
- 서브페이지도 동일한 글꼴을 사용합니다.
- 한국어 문장은 `default.css`의 `word-break: keep-all` 설정을 유지해 어절 단위로 자연스럽게 줄바꿈되도록 합니다.

### 주요 타이포그래피 기준

CSS에는 섹션별로 여러 크기가 정의되어 있습니다. 아래 표는 실제 선언된 대표 규칙을 용도별로 정리한 것이며, 모든 페이지에 강제로 적용하는 단일 스케일은 아닙니다.

| 용도 | 크기 및 굵기 | 행간 |
|---|---|---|
| GNB 메뉴 | PC 18px(기본 규칙), 일부 메뉴 16px / 500 | 1 또는 48px 높이 내 정렬 |
| Header 유틸리티 | 14px / 기본 굵기 | 1 |
| 섹션 제목 | `clamp(28px, 2.19vw, 36px)` 또는 섹션별 40px / 600 | 주로 1.2~1.25 |
| 혜택 카드 제목 | PC 25px / 600, 모바일 21px | 1.35 |
| 혜택 카드 설명 | PC 20px / 500, 모바일 16px | 1.5 |
| 상품 카드 제목 | 15~16px / 500 | 1.35~1.4 |
| 상품 가격·보조 정보 | 14px, 모바일 12px 또는 11px / 300 | 1.5 |
| Footer 소제목 | PC 19px / 600, 모바일 17px | 1.2 |
| Footer 본문 | PC 15px / 300, 모바일 13px | 주로 1.5~1.65 |

### 자주 쓰이는 굵기

- `300`: 보조 정보와 Footer 상세 정보
- `400`: 일반 링크 및 정책 링크
- `500`: 기본 메뉴, 설명, 카드 제목
- `600`: 섹션 제목, 카드의 주요 제목, Footer 소제목
- `700`: 브랜드 강조 텍스트 및 일부 활성 메뉴

### 타이포그래피 적용 규칙

- 제목과 본문을 크기와 굵기로 구분합니다.
- 제목의 기본 행간은 약 1.2~1.35, 본문은 약 1.4~1.5를 사용합니다.
- 제목의 자간은 기존 CSS에서 사용한 `-.02em`~`-.035em` 범위를 참고하되, 해당 컴포넌트의 실제 선언을 우선합니다.
- 모바일에서는 고정 크기 대신 기존 `clamp()` 규칙을 활용하는 영역이 있습니다.
- CSS 후반부에 공통 제목 크기를 다시 지정하는 규칙이 있으므로, 새 페이지에서 같은 선택자를 사용한다면 선언 순서와 우선순위를 확인합니다.

## 6. Layout & Spacing

### 공통 콘텐츠 컨테이너

메인 콘텐츠에서 반복적으로 사용되는 기본 이너 규칙은 다음과 같습니다.

```css
width: min(92%, 1480px);
margin: 0 auto;
```

- 화면 너비의 92%를 사용하되 최대 너비는 1480px로 제한합니다.
- 좌우 여백을 자동으로 동일하게 배분해 콘텐츠를 가운데 정렬합니다.
- 혜택, BEST/NEW, 리뷰, 렌즈 찾기, 매장 픽업 등 주요 섹션에서 같은 규칙이 반복됩니다.
- 서브페이지도 별도 이유가 없다면 이 컨테이너를 기준으로 사용합니다.
- Header는 별도 구조로 `max-width: 1720px`를 사용하므로 일반 콘텐츠 이너와 구분합니다.

### 주요 레이아웃 패턴

| 영역 | 레이아웃 | 현재 기준 |
|---|---|---|
| Header 내부 | Flex | 로고와 유틸리티, 내비게이션 정렬 |
| GNB | Flex | 가운데 정렬, 간격은 `clamp(24px, 3.65vw, 70px)` |
| 혜택 카드 | Grid | PC 3열, 모바일 1열, PC 간격 24px |
| PICK 카드 | Grid | PC 4열, 900px 이하 2열 |
| Footer 메인 | Grid | PC 2열, 900px 이하 1열 |
| Footer 회사 정보 | Grid | 항목명과 값의 2열 배치 |
| 상품·리뷰 | Swiper | 화면 너비에 따라 노출 개수 변경 |
| 매장 픽업 | Position + Flex | 텍스트와 배경 이미지 겹침 구성 |

### 간격과 모서리

- 콘텐츠 제목과 카드 목록 사이에는 주로 20~28px 간격을 사용합니다.
- 카드 목록 간격은 컴포넌트마다 다릅니다. 혜택은 24px, PICK은 PC 20px, 모바일 12px 등의 실제 규칙을 따릅니다.
- 카드 이미지의 둥근 모서리는 영역에 따라 16px, 18px, 20px, 24px, 28px 등으로 다릅니다.
- 모든 카드에 하나의 radius 값을 강제하지 말고, 유사한 기존 컴포넌트의 값을 재사용합니다.
- 섹션 상하 여백은 고정값과 `clamp()`가 함께 사용되므로 해당 섹션의 CSS를 기준으로 합니다.

### 정렬 규칙

- 섹션 제목과 전체보기 CTA는 `display: flex`, `justify-content: space-between`, `align-items: center` 조합을 사용합니다.
- 카드 그리드는 `minmax(0, 1fr)`를 활용해 콘텐츠가 열 너비를 넘치지 않게 합니다.
- 이미지가 카드 영역을 채우는 경우 `object-fit: cover`를 기본으로 사용합니다.
- 이미지 전체를 잘림 없이 보여야 하는 SVG나 모바일 전용 배너 등은 해당 컴포넌트의 `contain` 규칙을 따릅니다.

## 7. Components

### 7.1 Header

**구성**
- `.site-header`: 전체 Header
- `.header-inner`: 최대 너비 1720px의 내부 영역
- `.header-top`: 유틸리티와 로고, 모바일 메뉴 버튼
- `.header-utility`: 검색, 고객센터, 로그인/마이페이지, 장바구니 등
- `.header-logo`: 중앙 정렬된 브랜드 로고
- `.mobile-menu-button`: 모바일 메뉴 토글 버튼

**사용 규칙**
- PC에서는 상단 유틸리티와 중앙 로고, 하단 GNB를 유지합니다.
- 1024px 이하에서는 유틸리티를 숨기고 로고와 햄버거 메뉴를 표시합니다.
- 서브페이지에서도 Header의 높이, 로고 크기, 정렬을 임의로 변경하지 않습니다.
- 로고와 메뉴 링크는 프로젝트 내부 페이지 또는 실제로 연결이 확정된 기능으로 연결합니다. 임시 `#` 링크를 실제 목적지처럼 사용하지 않습니다.

### 7.2 GNB 및 서브메뉴

**구성**
- `.primary-navigation`
- `.nav-item`
- `.nav-highlight`
- `.nav-submenu`

**PC**
- 중앙 정렬 Flex 레이아웃입니다.
- 메뉴 사이 간격은 `clamp(24px, 3.65vw, 70px)`입니다.
- 메뉴 항목 Hover 또는 Focus 시 글자 굵기를 700으로 강조합니다.
- 서브메뉴는 상위 메뉴 아래에 배치됩니다.
- 내비게이션 Hover/Focus 시 전체 폭의 라벤더 서브메뉴 배경이 나타납니다.

**모바일 및 태블릿**
- 1024px 이하에서 세로형 메뉴로 전환됩니다.
- 상위 메뉴 클릭으로 서브메뉴를 열고 닫습니다.
- 펼쳐진 항목은 `.is-expanded` 클래스로 표시합니다.
- 상위 메뉴의 `aria-expanded` 값도 상태와 함께 변경해야 합니다.

### 7.3 CTA 및 전체보기 버튼

- 단, Hero 예약 버튼은 별도 규칙(125px 너비, 최소 높이 44px)을 가지므로 공통 CTA 크기와 구분합니다.

**사용 규칙**
- 버튼 문구는 행동을 구체적으로 표현합니다. 예: 예약하기, 더 찾아보기, 매장찾기.

## 8. Interaction

### Hover / Focus / Active

| 대상 | 상태 | 동작 |
|---|---|---|
| GNB 메뉴 | Hover, Focus-within, 펼침 | 메뉴 글자 굵기 700 |
| GNB 서브메뉴 링크 | Hover, Focus-visible | 글자 굵기 700 |
| 전체보기 CTA | Hover, Focus-visible | 기본 SVG를 Hover SVG로 전환 |
| 전체보기 CTA | Active | `scale(0.97)` |
| 렌즈 찾기 CTA | Hover, Focus-visible | SVG 이미지와 글자 색상 전환 |
| 렌즈 찾기 CTA | Active | `scale(0.97)` |
| 매장 픽업 버튼 | Hover, Focus-visible | 배경색을 `#625087`로 변경 |
| 상품 좋아요 | Click | `aria-pressed`, 라벨, 하트 이미지 변경 |
| 모바일 메뉴 | Click | `.is-open` 클래스와 `aria-expanded` 변경 |
| 모바일 GNB | Click | `.is-expanded` 클래스와 `aria-expanded` 변경 |
| Swiper | Pagination / Autoplay | 슬라이드 이동 및 페이지네이션 상태 변경 |

### Transition

- 전체보기와 렌즈 찾기 CTA는 주로 180ms `ease` 전환을 사용합니다.
- 일부 메뉴 글자 굵기 전환은 150ms입니다.
- 매장 픽업 버튼은 배경색을 200ms 전환합니다.
- 새 컴포넌트도 불필요하게 과한 모션을 추가하지 않고 기존의 짧고 부드러운 전환을 참고합니다.

### 접근성 및 모션

- 키보드 조작 요소에는 `:focus-visible` 스타일을 제공합니다.
- 기본 Reset에서 `:focus` outline을 제거하므로, 인터랙션 요소에 `:focus-visible`을 직접 지정하는 것을 잊지 않습니다.
- 버튼의 상태를 표현할 때 `aria-expanded`, `aria-pressed` 등을 실제 UI 상태와 동기화합니다.
- `prefers-reduced-motion: reduce` 설정에서는 transition과 animation을 줄입니다.
- 클릭 가능한 요소는 실제 기능을 수행해야 하며, 장식용 요소를 버튼처럼 보이게 만들지 않습니다.

## 9. Responsive Rules

### 현재 CSS의 주요 분기점

| 미디어 조건 | 적용 기준 |
|---|---|
| `max-width: 1100px` | 일부 브랜드 소개 섹션의 이미지와 텍스트 크기 조정 |
| `max-width: 1024px` | Header 모바일 메뉴 전환, GNB 세로형 전환, 혜택 섹션 간격 조정 |
| `max-width: 900px` | PICK 2열 전환, Footer 1열 전환 |
| `max-width: 768px` | Swiper 설정에서 태블릿 슬라이드 노출 수 조정 |
| `max-width: 640px` | 주요 콘텐츠 모바일 레이아웃, 카드 1열, 텍스트 및 버튼 축소 |
| `max-width: 600px` | Footer의 모바일 세부 크기 조정 |
| `max-width: 480px` | Hero 비주얼 높이 조정 |
| `prefers-reduced-motion: reduce` | 모션 최소화 |

### 반응형 적용 원칙

**1024px 이하**
- Header 유틸리티를 숨기고 햄버거 메뉴를 표시합니다.
- GNB는 세로형으로 바뀌며 메뉴별 서브메뉴를 펼칠 수 있습니다.
- Hero의 PC 이미지를 숨기고 모바일 이미지를 표시하는 규칙이 적용됩니다.

**900px 이하**
- Footer 메인 영역은 2열에서 1열로 변경됩니다.
- PICK 상품 목록은 4열에서 2열로 변경됩니다.

**640px 이하**
- 혜택 카드는 1열로 변경됩니다.
- 모바일 전용 이미지가 있는 경우 모바일 이미지를 표시합니다.
- 섹션 제목, 카드 제목, 설명, 버튼 크기를 축소합니다.
- PICK 카드는 2열을 유지합니다.

**480px 이하**
- Hero 높이는 `100vh`를 사용합니다.

### 반응형 제작 시 주의

- 기존 메인페이지의 브레이크포인트를 임의로 다른 값으로 바꾸지 않습니다.
- 화면 너비가 줄어들 때 단순히 요소를 축소하기보다 Grid 열 수, Flex 방향, 이미지 비율을 조정합니다.
- PC/모바일 이미지가 분리된 콘텐츠는 HTML의 `.pc`, `.mo` 클래스와 CSS 표시 규칙을 함께 확인합니다.
- 모바일에서 텍스트 색상, 이미지 비율, CTA 크기가 PC와 다르게 의도치 않게 바뀌지 않는지 확인합니다.
- Footer와 고정 플로팅 메뉴가 작은 화면에서 콘텐츠를 가리지 않는지 확인합니다.

## 10. Do & Don't

### Do

- [ ] `"Pretendard Variable", Pretendard, sans-serif`를 기본 글꼴로 사용합니다.
- [ ] 기본 콘텐츠 이너는 `width: min(92%, 1480px)`를 우선 사용합니다.
- [ ] CSS 변수 `--color-*`를 먼저 확인하고 기존 컬러를 재사용합니다.
- [ ] Header, GNB, Footer의 기존 구조와 반응형 동작을 유지합니다.
- [ ] 카드와 버튼은 유사한 기존 컴포넌트의 클래스 및 수치를 참고합니다.
- [ ] Hover, Focus-visible, Active 상태를 필요한 인터랙션 요소에 정의합니다.
- [ ] 모바일에서 Grid 열 수와 정렬, 이미지 비율을 확인합니다.
- [ ] 실제 동작하는 링크와 버튼을 사용하고 접근성 속성을 상태와 동기화합니다.
- [ ] `prefers-reduced-motion`을 고려합니다.
- [ ] CSS 후반부의 재정의 규칙까지 확인해 최종 적용값을 판단합니다.

### Don't

- [ ] 기존 팔레트와 무관한 새 브랜드 컬러를 임의로 추가하지 않습니다.
- [ ] 근거 없이 새로운 최대 너비, 여백, 폰트 크기, radius를 만들지 않습니다.
- [ ] 메인 페이지의 Header, GNB, Footer 디자인을 서브페이지 작업 중 변경하지 않습니다.
- [ ] 모든 카드에 동일한 이미지 비율이나 radius를 강제로 적용하지 않습니다.
- [ ] Hover만 정의하고 키보드 Focus 상태를 누락하지 않습니다.
- [ ] 링크 목적지가 정해지지 않았는데 실제 사이트나 외부 브랜드 사이트 주소를 임의로 연결하지 않습니다.
- [ ] 기능이 없는 요소를 링크나 버튼처럼 보이게 만들지 않습니다.
- [ ] 모바일에서 PC 레이아웃을 그대로 축소해 글자와 버튼이 지나치게 작아지게 하지 않습니다.
- [ ] 기존에 사용 중인 Swiper를 확인하지 않고 불필요한 슬라이더 라이브러리를 추가하지 않습니다.
- [ ] Reset의 `:focus { outline: none; }` 설정만 믿고 Focus-visible 스타일을 생략하지 않습니다.

## Implementation Notes

### 실제 파일 연결 관계

- `Lensme/index.html`에서 `../css/default.css`를 불러옵니다.
- Pretendard는 `../font/css/pretendardvariable.css`에서 불러옵니다.
- Swiper CSS/JS는 `../npm/swiper/swiper-bundle.min.css`, `../npm/swiper/swiper-bundle.min.js`에서 불러옵니다.
- 메인 페이지 CSS는 `Lensme/css/main.css`입니다.
- 메인 페이지의 Swiper 및 메뉴, 좋아요 동작은 현재 `index.html` 하단의 인라인 JavaScript에서 초기화됩니다.

### CSS 우선순위 확인

현재 `main.css`에는 같은 컴포넌트 선택자가 파일 뒤쪽에서 다시 선언된 부분이 있습니다. 따라서 위 가이드의 값은 확인된 주요 규칙을 정리한 것이며, 새 페이지를 구현할 때는 해당 요소에 적용되는 CSS 선언의 위치와 미디어쿼리, 선택자 우선순위를 함께 확인해야 합니다.

특히 CTA 공통 크기, 섹션 제목 크기, 렌즈 찾기 버튼, Footer 간격처럼 후반부에 재정의가 있는 항목은 파일의 마지막 선언이 실제 화면에 적용될 수 있습니다.

### 링크 정책

이 문서는 디자인 시스템 기록용입니다. 기존 브랜드 공식 사이트로 연결되는 링크를 추가하지 않습니다. 서브페이지 내 이동은 프로젝트 안에서 실제로 제작된 페이지 경로를 사용하고, 아직 목적지가 정해지지 않은 링크는 연결 작업 전까지 임의의 외부 URL을 넣지 않습니다.
